# Spectral data sources for Kubelka-Munk (research, 2026-11-26)

Kubelka-Munk (KM) mixing needs per-pigment reflectance spectra (ideally K and S, which need tints
or a white/black ladder). Candidate sources, as far as could be verified from their public pages.
Nothing here is bundled in the repo yet.

## Related code (not data)

- [Spectral.js](https://www.npmjs.com/package/spectral.js) (MIT): KM mixing from RGB inputs by
  reconstructing spectra from 7 base channels; single-constant form. A cheap way to try KM-style
  mixing before real pigment spectra exist (like Mixbox, it only sees colors).
- Mixbox's paper (Sochorova & Jamriska, TOG 2021) fits KM-based latent space to four real pigments.

## Modeling caveats

- A single masstone reflectance gives only K/S at 100% pigment. Single-constant KM (S equal for all
  pigments) works from masstones but misrepresents opaque vs transparent pigments. Two-constant KM
  needs tints with white (and black) per pigment.
- Different binders, thickness, substrates and geometries change spectra; mixing data from
  several sources needs care.
